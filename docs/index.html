📋 Collecta

Schema-driven field data collection: form schemas, validation, JWT auth, and a sync protocol. Server and shared library, no field app yet.

Features

📝 Form Schemas

20+ field types with conditional logic, validation constraints, and XLSForm-compatible structure.

📡 Sync Protocol

Idempotent submission push and cursor-based form pull. A SyncQueue library type with exponential backoff retry is provided for a client to drive.

📎 Attachments (deferred)

Photo, audio, video, signature, and barcode exist as form field types, and an Attachment struct exists in the core library. The server has no upload endpoint and no blob storage, so nothing captures a photo today.

🌍 GPS Field Types

Point, trace, and shape geometry types in the form model, with latitude, longitude, altitude, and accuracy. Capture happens in the client.

✅ Validation

Required fields, numeric range checks, text length, glob-style patterns, and OneOf sets. All errors are reported, not just the first.

🔌 REST API

Axum server for form CRUD, XLSForm import, submission ingestion, and sync, persisted to SQLite. JWT auth with argon2id hashing.

Status

Collecta aims to be an open-source alternative to ArcGIS Field Maps, KoboToolbox, and ODK Collect. Today it is the server and the shared schema library, not the field app.
